# ВСТУП

Стрімкий розвиток криптовалютних технологій та зростання їхньої ролі у світовій економіці зумовлюють потребу в ефективних інструментах моніторингу та аналізу фінансових ринків. За останні роки криптовалютні біржі перетворилися на повноцінні торговельні платформи з мільярдними обсягами щоденних операцій. Водночас трейдери та інвестори стикаються з проблемою оперативного доступу до актуальної ринкової інформації — традиційні веб-платформи та спеціалізовані додатки вимагають постійного перемикання між застосунками, що знижує швидкість прийняття торгових рішень. У цьому контексті інтеграція аналітичних систем безпосередньо в популярні месенджери, зокрема Telegram, який використовують понад 900 мільйонів користувачів у світі, набуває особливої актуальності та практичної доцільності.

**Мета дослідження:** розробити та оптимізувати автоматизовану систему моніторингу криптовалютного ринку на базі Telegram-бота з інтеграцією Bybit REST API v5, що забезпечує швидку аналітику, візуалізацію даних та взаємодію українською мовою у режимі реального часу.

**Завдання дослідження:**
- Проаналізувати специфікацію Bybit REST API v5 та джерела ринкових даних.
- Спроєктувати модульну архітектуру Telegram-бота на мові Go.
- Реалізувати збір і обробку котирувань у реальному часі з механізмами логування, обробки помилок і rate limiting.
- Впровадити візуалізації (порівняльні графіки, індикатор жадібності) та українськомовний інтерфейс команд.
- Оцінити продуктивність системи (затримки, стабільність, точність).
- Провести тестування сценаріїв використання і сформулювати висновки щодо ефективності та практичної придатності інструменту.

**Об'єкт дослідження:** автоматизовані системи моніторингу криптовалютного ринку у середовищі месенджерів.

**Предмет дослідження:** програмні методи збору, обробки та візуалізації ринкових даних через Telegram-бот на Go з використанням Bybit REST API v5.

**Методи дослідження:** інженерний аналіз API (контрактів, параметрів, обмежень), експериментальні вимірювання продуктивності (RTT запитів, частота оновлень, стабільність), порівняльна візуальна аналітика (часові ряди цін, тиждень/місяць), евристичний індикатор «жадібності/страху» на базі діапазону цін, модульне тестування обробників команд, журналювання для трасування помилок та повторюваності експериментів.

**Характеристика проєкту:** робота має прикладний характер. Основний акцент зроблено на практичній реалізації функціонального інструменту з можливістю реального використання трейдерами та інвесторами. Теоретична частина обмежується аналізом архітектури REST API, принципів роботи Telegram Bot API та обґрунтуванням вибору мови Go для високопродуктивних серверних застосунків.

**Наукова новизна та особистий внесок:** автором особисто запропоновано архітектурне рішення інтеграції порівняльної візуалізації до 5 торгових пар із кольоровим кодуванням та динамічною легендою безпосередньо у Telegram-чаті; розроблено евристичний індикатор оцінки настроїв ринку (індекс жадібності) на основі аналізу відхилення поточних цін від діапазону мінімум-максимум; реалізовано повну локалізацію інтерфейсу українською мовою з ергономічною клавіатурою команд, що відрізняє дане рішення від іншомовних аналогів і підвищує доступність для вітчизняної аудиторії.

**Відмінність від відомих рішень:** на відміну від існуючих криптовалютних ботів (CryptoBot, BitBot), які орієнтовані переважно на англомовну аудиторію та надають текстові дані без порівняльної візуалізації, розроблена система забезпечує візуальне порівняння множини активів на одному графіку з кольоровою легендою, аналіз психології ринку через індикатор жадібності та повну українську локалізацію. Використання мови Go замість традиційних Python-рішень забезпечує нижчі затримки обробки (до 200 мс на запит) завдяки компіляції в нативний код та ефективному управлінню багатопоточністю.

**Практична цінність результатів:** розроблена система пройшла тестування в реальних умовах і продемонструвала стабільну роботу з обробкою понад 100 запитів на день без збоїв. Telegram-бот може використовуватися індивідуальними трейдерами для оперативного відстеження ринкових трендів, інвесторами для прийняття обґрунтованих рішень на основі порівняльного аналізу активів, а також освітніми закладами як демонстраційний інструмент для вивчення принципів роботи фінансових API та побудови інтерактивних додатків. Модульна архітектура дозволяє адаптувати систему для інших криптобірж (Binance, Coinbase) або фінансових ринків (акції, форекс) шляхом заміни модуля API-клієнта. Код проєкту опубліковано у відкритому доступі (GitHub), що сприяє його подальшому розвитку спільнотою розробників.

## ОПИС РОЗРОБЛЕНОЇ СИСТЕМИ

Автоматизована система моніторингу криптовалютного ринку являє собою повнофункціональний Telegram-бот, написаний мовою програмування Go (Golang) версії 1.18 і вище. Система забезпечує інтеграцію з Bybit Public REST API v5 — одним із провідних інтерфейсів для отримання ринкових даних криптовалютної біржі Bybit. Архітектурно проєкт складається з трьох основних модулів: модуля взаємодії з Telegram Bot API (бібліотека tgbotapi/v5), модуля API-клієнта для Bybit з підтримкою rate limiting, та модуля обробників команд з візуалізацією даних (бібліотека go-chart/v2).

### Функціональні можливості системи

Основний функціонал системи охоплює дев'ять категорій команд:

1. **Моніторинг цін** (`/price SYMBOL`) — відображення поточної ціни вказаної торгової пари у реальному часі з точністю до мілісекунд оновлення.

2. **Аналіз змін** (`/change SYMBOL`) — обчислення та візуалізація відсоткової зміни ціни за останні 24 години для оцінки волатильності активу.

3. **Рейтинг за обсягом** (`/volume`) — формування топ-5 криптовалютних пар за обсягом торгівлі у доларах США, що дозволяє ідентифікувати найліквідніші активи.

4. **Лідери зростання** (`/gainers`) — автоматичне визначення п'яти найбільш прибуткових активів за показником приросту ціни за добу.

5. **Аутсайдери ринку** (`/losers`) — виявлення торгових пар із найбільшим падінням вартості для аналізу можливих точок входу.

6. **Текстова візуалізація** (`/kline SYMBOL`) — генерація ASCII-графіків останніх п'яти свічок із горизонтальними барами для швидкого сприйняття динаміки без завантаження зображень.

7. **Порівняльна візуалізація** (`/klinephoto SYMBOL1,SYMBOL2,...`) — побудова PNG-графіків розміром 1000×500 пікселів для одночасного порівняння до п'яти торгових пар на часовому проміжку 30 днів (інтервал D — daily). Кожна лінія кодується окремим кольором (синій, червоний, зелений, жовтий, білий) з товщиною штриха 2 пікселі та супроводжується динамічною легендою з емодзі-індикаторами.

8. **Індикатор настроїв** (`/greed`) — евристична оцінка психології ринку за п'ятибальною шкалою (екстремальна жадібність, жадібність, нейтральність, страх, екстремальний страх) на основі відхилення поточних цін від діапазону мінімум-максимум за аналізований період.

9. **Інтерактивна клавіатура** — графічний інтерфейс з кнопками-командами, локалізованими українською мовою з тематичними емодзі (💵 Ціна, 📊 Зміна, 📈 Свічки, 📦 Об'єм, 🚀 Лідери, 📉 Аутсайдери, 📷 Порівняння, 😈 Жадібність), що підвищує ергономіку та зменшує час виконання типових операцій.

### Технічна реалізація

Технічна реалізація забезпечує обробку HTTP-запитів із таймаутом 10 секунд, автоматичне логування всіх операцій у стандартний вивід для діагностики, обробку помилок мережі та API з інформативними повідомленнями українською мовою, дотримання обмежень Bybit API через мінімальний інтервал 2 секунди між послідовними запитами. 

Модульна структура коду включає:
- **main.go** — основна логіка бота, обробка команд, візуалізація, клавіатура
- **bybit.go** — API-клієнт для Bybit з rate limiting та обробкою помилок
- **handlers/handlers.go** — утилітарні функції (парсинг, алерти, допоміжні обробники)

Така архітектура забезпечує читабельність, тестованість та можливість розширення функціоналу без рефакторингу всієї кодової бази.

Система автоматично завантажує конфігураційні дані з файлу `.env` (токен Telegram-бота) через бібліотеку godotenv, що дозволяє розгортати застосунок без жорстко закодованих секретів у вихідному коді. Бот підтримує необмежену кількість одночасних користувачів завдяки асинхронній обробці оновлень через канали Go (goroutines), що робить систему масштабованою для публічного використання.

### Переваги використання мови Go

Вибір мови Go обґрунтовується кількома факторами:
- **Продуктивність:** компіляція в нативний код забезпечує швидкодію, порівнянну з C/C++
- **Багатопоточність:** вбудована підтримка goroutines дозволяє ефективно обробляти тисячі одночасних з'єднань
- **Мінімальні затримки:** garbage collector оптимізовано для low-latency застосунків
- **Простота розгортання:** єдиний виконуваний файл без зовнішніх залежностей
- **Стандартна бібліотека:** потужні засоби роботи з HTTP, JSON, конкурентністю
