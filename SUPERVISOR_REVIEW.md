Науково-дослідницька робота присвячена розробці автоматизованої системи моніторингу криптовалютного ринку на базі Telegram-бота з інтеграцією Bybit REST API v5. Молодий дослідник вдало висвітлив актуальні тенденції сучасного світу, пов'язані з бурхливим розвитком криптовалютних технологій та зростанням потреби у швидкому доступі до фінансової інформації, зосереджуючись на інтеграції автоматизованих систем аналітики в популярні месенджери.

Особливу увагу автор приділив важливості забезпечення високої ефективності обробки запитів та реалізації аналітичних функцій у режимі реального часу під час взаємодії з користувачами. Bybit REST API v5 виступає ключовим інструментом для досягнення цих цілей, а інтеграція його в Telegram розширює можливості розвитку фінансових ботів та поліпшення їх функціоналу. Захоплює також і мета роботи — надати розширений огляд можливостей використання мови програмування Go для фінансових додатків у реальному часі та розробити методи оптимізації для досягнення ефективної взаємодії з користувачами через візуалізацію даних та багатопоточну обробку.

Інтеграція візуалізації порівняльних графіків, індексу жадібності ринку та українськомовного інтерфейсу відкриває нові перспективи для криптовалютних моніторингових систем, що може призвести до покращення користувацького досвіду трейдерів шляхом надання більш швидких та інформативних інструментів аналізу. Автором зазначається, що розроблена система має практичне значення, спрямована на автоматизацію аналізу ринкових тенденцій, оперативне отримання аналітичної інформації та підтримку прийняття торгових рішень. Це відкриває нові перспективи для інтерактивної комунікації та покращення користувацького досвіду інвесторів в умовах стрімкого розвитку фінансових технологій. Також це може мати величезне практичне значення в різних сферах, від індивідуальної торгівлі до професійного трейдингу та фінансового консалтингу.

Дослідження чітко структуроване, в ньому простежується певна логіка доведення. Робота складається з трьох розділів: теоретичного (аналіз Bybit API, Telegram Bot API, переваг Go), практичного (архітектура системи, модульна структура, візуалізація) та результативного (функціональні можливості, тестування, оцінка продуктивності). У кінці роботи чітко сформульовані висновки про ефективність Go для фінансових додатків, переваги інтеграції API у месенджери та практичну придатність системи. Мету дослідження досягнуто за рахунок успішного вирішення поставлених завдань: реалізовано 9+ команд моніторингу, порівняльні графіки з кольоровим кодуванням, повну локалізацію українською та стабільну роботу в режимі реального часу з дотриманням rate limiting.

Пропонована робота заслуговує уваги та схвалення за ґрунтовність і змістовність викладених результатів дослідження. Автор продемонстрував високий рівень самостійності, технічної компетентності та здатності доводити проєкт до практичного застосування. Рекомендую роботу до участі в Конкурсі-захисті науково-дослідницьких робіт учнів-членів Малої академії наук України.
